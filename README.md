# 雀运骰 🎲

线下麻将神器 · 每局都是惊喜

## 项目简介

雀运骰是一款为线下麻将爱好者打造的趣味工具，灵感来源于《金铲铲之战》的海克斯科技和城邦机制。它能让每局麻将都充满惊喜，为传统麻将增添更多趣味性和不确定性。

## ✨ 功能特性

- 🎲 **骰面系统**：每人随机抽取1-3张个人效果牌，有增益有减益，搞怪又刺激
- 🌌 **骰域系统**：每局/每圈摇一个全局效果，所有人共用
- 📖 **图鉴功能**：无需开局即可浏览所有骰面和骰域
- 🏠 **房间系统**：创建密码保护的房间，6位随机房间码
- 💾 **数据持久化**：支持离线使用，自动保存游戏进度
- 📱 **响应式设计**：支持手机和电脑访问

## 🎮 玩法说明

1. **创建房间**：选择玩法（大众麻将、四川麻将、日本麻将等）、设置人数
2. **摇骰域**：系统随机生成一个全局效果
3. **抽骰面**：每人随机获得1-3张个人效果牌
4. **开打!**：按骰面效果打牌，体验不一样的麻将乐趣

## 🎴 支持玩法

- 大众麻将（258将）
- 四川麻将（血战到底）
- 日本麻将（立直麻将）
- 广东麻将（鸡平胡）
- 台湾麻将（16张牌）
- 东北麻将（推倒胡）
- 推倒胡
- 自定义规则

## 📦 安装使用

无需安装，直接打开浏览器访问即可：

```bash
# 方式1：本地打开
直接用浏览器打开 index.html

# 方式2：启动本地服务器
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```
